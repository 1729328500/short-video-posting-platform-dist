使用说明

首次使用：素材库上传视频 → 发布台写文案（可一键生成 8 平台版）→ 账号页逐个登录 → 发布台③勾选平台一键发布（队列执行、进度可视）；记录页可查历史/重试，数据页每天播报。
常见问题：① 登录全在网页里完成，不用在自己电脑上装任何东西；各平台支持的登录方式不一样（有的扫码、有的只有账号密码），都能在【直接操作浏览器】里做完，登录态长期保持；② 数据（视频 / 登录态 / 发布记录）全部在服务器上，不在各自电脑；③ 忘记访问口令：让管理员在服务器上重设（docker run --rm -v .../data:/data <镜像> --set-password '新口令'），或删掉 data/auth.json（口令单独存这个文件，删了就是重置为无口令）。
