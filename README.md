# 短视频发布台

当前桌面架构版本：**1.10.1**。业务程序、固定启动器、运行环境与个人数据已分离。

- 源码启动：项目根运行 `python -X utf8 launcher/start.py --dev --no-updates`。
- 同事使用：完整绿色包解压后双击 `Install.bat` / `Start.bat`，无需 Git 或 Python。
- 安装、数据迁移、打包和更新机制：[桌面包说明](launcher/README.md)。
- 架构与验收任务：[实施计划](12-桌面端-实施计划.md)。
- 分发仓库：[Gitee](https://gitee.com/guizhou-jubangbang_0/short-video-posting-platform-dist)。

本地源码仓不向公开分发仓上传。个人数据和本机配置排除在 Git 和更新包之外。
完整包在开发机自检后，还需同事的干净 Windows 电脑验收；当前未执行公开发布。

平台账号登录成功后，先保存登录态，再自动关闭整个登录浏览器。下次启动工具、发布或采集
会继续使用个人数据目录里的登录态，无需每次扫码；关闭登录窗口也不会退出已完成的登录。
平台主动过期或撤销会话时仍需重新登录。登录态备份属于私人数据，不进入源码仓或分发包。
