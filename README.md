# 短视频发布台 · 下载与更新

面向 Windows 用户的短视频发布工具。这个公开仓库用于分发安装包、更新包和使用说明，方便同事直接下载使用。

**使用者不需要安装 Git，也不需要执行 Git 命令。** 完整绿色包将包含程序运行所需的 Python 环境和浏览器文件。

> 当前状态：分发仓库已初始化，桌面绿色包尚未发布。安装、登录、发布和自动更新验收通过后，才会提供可用的下载包。

发布后，请在发行版页面下载标为“Windows 完整绿色包”的 ZIP 文件。单独的程序更新包用于已有安装，不能代替完整绿色包。

仓库页面的“下载源码 / Download ZIP”只包含本仓库文件，不是可运行的安装包。

## 发布绿色包后的安装方法

1. 下载 Windows 完整绿色包 ZIP，将它完整解压到一个固定目录。
2. 双击包内的 `安装.bat`，选择素材、登录状态和发布记录的存放目录。
3. 按需要创建桌面快捷方式，并选择是否在登录 Windows 后自动启动。
4. 双击 `启动工具.bat` 或桌面快捷方式，等待浏览器打开工具页面。
5. 在账号页面登录自己的平台账号，再上传素材并进行发布。

请保留解压后的整个程序目录。运行时不要直接在 ZIP 压缩包中双击启动文件。

每个人使用自己电脑上的数据目录。素材、平台登录状态、发布记录及个人配置都保存在该目录中。

## 更新与日常使用

桌面启动器完成验收后，将按安装包配置的更新地址，在启动时检查新版本并下载更新。更新只替换程序目录；更新失败时继续使用已安装版本。

这个过程通过普通 HTTP/HTTPS 下载完成，同事不需要克隆仓库，也不需要执行 `git pull`。

使用定时发布或播报时，需要保持工具运行。电脑关机或休眠期间，到点任务不会正常执行。

从 NAS 版迁移的用户需要在本机重新登录平台。素材可通过工具界面重新上传；仅复制视频文件夹不会自动生成素材列表记录。

## 下载与启动遇到问题

- 发行版页面没有安装包：说明该版本尚未发布，请等待正式发布。
- 下载链接打开后要求登录或不能下载：向维护者反馈完整链接，先确认分发入口是否已经公开。
- 绿色包没有完整解压，或缺少运行环境：重新下载完整绿色包并完整解压。
- 启动失败：把界面提示或启动窗口中的错误信息发给维护者，并附上正在使用的版本号。

## 维护者：发布约定

这个仓库只维护以下文件：

| 位置 | 用途 |
| --- | --- |
| `README.md` | 下载入口与使用说明 |
| `LICENSE` | 建仓时已有的许可证 |
| `.gitignore` | Git 文件白名单 |
| `dist/version.json` | 正式发布后生成的更新清单 |
| `release-notes/*.md` | 各版本发布说明 |

完整绿色包和程序更新 ZIP 作为发行版附件上传。尚未产出并验证真实更新包时，不提交占位的 `version.json`。

发布前确认版本号、文件名、下载地址、文件大小及校验值与实际安装包一致。先上传并验证安装包，再发布更新清单。

每个下载入口必须用无 Cookie、无 Token 的请求实际验证，确认得到的是 ZIP 文件或合法 JSON。仅看到 HTTP 200，不能证明下载内容正确。

`.gitignore` 默认忽略其他文件；提交时仍需显式选择文件，并检查暂存清单。项目工作目录中的素材、数据库、浏览器登录目录、个人配置、口令、密钥、交接文档、截图、缓存及临时文件不属于分发内容。
