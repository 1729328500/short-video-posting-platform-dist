# 短视频发布台 · 安装与登录说明（v1.11.0）

> 给使用它的人看的一份说明。不需要懂命令行，不需要装 Git 或 Python。
> 2026-10-06

## 一、拿到安装包

三个来源，**优先用前两个**（GitHub 在国内可能慢）：

| 来源 | 说明 |
| --- | --- |
| 公司内网 | 直接拿现成的文件夹，跳到第二节 |
| 同事拷给你 | 同上 |
| GitHub Releases | <https://github.com/1729328500/short-video-posting-platform-dist/releases> 找 **v1.11.0**，下载 `shipin-fabu-1.11.0.zip`（约 399 MB） |

## 二、解压

**完整解压**到一个固定目录再动它，别在压缩包里直接双击。

- 建议放在比如 `D:\短视频发布台\` 这种**不带空格、路径不太深**的地方。
- 中文路径没问题（已经验证过）。
- 解压出来应该能看到 `Start.bat`、`Install.bat`、`app`、`runtime`、`browsers`、`launcher` 这几项。
- **这个目录要留着、要可写** —— 程序更新靠替换这里面的文件。别放到只读盘或共享盘上。

## 三、安装（只做一次）

双击 **`Install.bat`**，它会问你两件事：

1. **数据目录** —— 你的素材、发布记录、平台登录态都放这里。
   直接回车用默认（`%LOCALAPPDATA%\shipin-fabu\data`）就行。
   想放到别处也可以，但**不要选到程序目录里面**（不能和 `app`、`runtime`、`browsers`、`launcher` 重叠）。
2. **登录 Windows 后自动启动** —— 一般选 `n`（不开）。

然后它会建一个桌面快捷方式。看到「配置已保存」就成了。

> 以后重装或换版本时再跑一次 `Install.bat` 也没关系，它会**保留你原来的设置**。

## 四、启动

双击桌面上的快捷方式（或目录里的 **`Start.bat`**）。会弹出一个窗口，然后自动打开浏览器。

**用完关那个窗口就退出了** —— 服务和它开的浏览器会一起结束。别只关浏览器窗口，那样服务还在后台跑。

## 五、第一次用

1. **上传素材**：进「素材库」→ 上传视频。
   ⚠️ **直接把视频文件拷进数据目录是不会出现在素材库里的**，必须走上传入口。
2. **登录平台**：进「账号」→ 点要用的平台。「本机浏览器登录」模式下会弹出登录窗，扫码/验证码/账号密码都在那个窗口里完成。
3. **发布**：回「发布台」选素材、填文案、勾平台。第一次用建议先只勾一个平台试。

## 六、登录这件事，注意三点

1. **登录成功后窗口会自己关**，登录态自动保存 —— 不用你手动关。
2. **万一它没自动关**（平台页面改版、或碰到维护页），窗口会留着 —— 这时候你在窗口里确认确实登好了，回账号页点那颗**「已登录（手动）」**按钮收尾。
3. **平台自己让登录过期后要重新登录**，这是平台的行为，工具延长不了。

> ⚠️ 不要把别人电脑上的登录态拷到自己电脑上。一台电脑一个账号体系，混用会互相顶掉。

## 七、更新

启动时会自动检查更新，有新版本会自己换掉程序部分（几 MB），**你的素材、记录、登录态都不动**。

- 更新失败或断网 → 照常用旧版，不阻塞你干活。
- 每次更新前不用你做什么，也不用重新登录。

### 如果提示「需要重新下载完整包」

说明新版换了运行环境，纯更新做不到。**这时候千万别直接解压覆盖旧文件夹** —— 那会连你的数据目录设置一起覆盖掉，看起来就像素材全丢了。

照这个顺序做：

1. 先**看一眼你现在的数据目录**（素材和登录态都在那儿）：
   打开旧文件夹里的 `install.json`，里面有 `"data_dir": "..."` 那一行，把它记下来。
2. 把新的完整包**解压到一个新文件夹**（不要覆盖旧的）。
3. 双击新文件夹里的 `Install.bat`。问「数据目录」时，**把第 1 步记下的那个路径原样填进去**（不填直接回车会切回默认目录，就别怪素材不见了）。
4. 双击 `Start.bat` 启动，确认素材和账号都还在。
5. 都正常了，再把旧文件夹删掉。

## 八、出问题了怎么办

| 现象 | 先看这里 |
| --- | --- |
| 启动失败 / 闪一下就没了 | 数据目录里的 `logs/server.log` |
| 页面打不开 | 确认那个黑窗口还开着（关了就退出了） |
| 素材不见了 | 先确认上传时用的是**同一个数据目录** |
| 平台显示没登录 | 账号页点一次「核验」，或重新登录 |

拿不准的时候**先把数据目录整个备份一份**再折腾，比什么都强。

## 九、别做的事

- ❌ 别在压缩包里直接运行。
- ❌ 别把程序目录放到只读盘、共享盘、或会同步的网盘目录里。
- ❌ 别删数据目录 —— 素材、发布记录、平台登录态都在里面。
- ❌ 别把同事的登录态拷过来。
- ❌ 别在程序目录里手动改文件，更新会覆盖掉。
